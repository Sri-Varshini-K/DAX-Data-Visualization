# E-Commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data using **Microsoft Power BI**. It demonstrates data modeling, DAX calculations, and interactive data visualization to understand sales trends, profitability, and sales target achievement.

## Objectives
- Analyze e-commerce sales and profitability.
- Create calculated columns and DAX measures.
- Establish relationships between data tables.
- Compare actual sales with sales targets.
- Build interactive visualizations to identify business insights.

## Dataset
The project uses the following datasets:
- List of Orders
- Order Details
- Sales target

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)


## Tasks Performed

### 1. Calculated Columns
- **Category Type:** Combines Category and Sub-Category.
- **Revenue per Order:** Calculates revenue using Amount × Quantity.
- **Sales Category:** Classifies sales as Above Average or Below Average based on Amount.

### 2. DAX Measures
- **Order Count:** Calculates the total number of orders.
- **Average Profit in Delhi:** Calculates average profit for orders placed in Delhi.
- **Year-to-Date (YTD) Sales:** Calculates cumulative sales from the beginning of the year up to each order date.

### 3. Data Visualizations
The dashboard includes the following visualizations:

- **Clustered Column Chart:** Actual sales versus sales targets by category.
- **Donut Chart:** Maximum profit margin by sub-category.
- **Line Chart:** Monthly sales trends.
- **Scatter Chart:** Profit versus quantity by sub-category.
- **Cards:** Total sales amount and sales target.
- **Multi-Row Card:** Minimum target for each segment.
- **Matrix:** Sales performance by category and month.
- **Map:** Geographic sales analysis by city.
- **Treemap:** Sales distribution by sub-category.
- **Funnel Chart:** Order count analysis by state.

## Key Learnings
- Data modeling and table relationships in Power BI.
- Creating calculated columns and measures using DAX.
- Designing interactive and meaningful dashboards.
- Comparing sales performance against business targets.
- Analyzing geographical and monthly sales patterns.
